# Publication

[Home](../README.md)

This is an independent English-only source distribution, with its own Git history.
It includes verified Lean sources, knowledge cards, a verifier CLI, CI, and the
Apache-2.0 license. Development history and working notes are not part of this
source distribution. The Lean toolchain and dependency versions remain pinned.

[Reservoir inclusion criteria](https://reservoir.lean-lang.org/inclusion-criteria)
require a public repository that is not a fork or template-generated repository,
a root lake-manifest.json, a GitHub-recognized OSI-approved license, and at least
two stars. Indexing is automatic and approximately daily. No indexing success is
claimed until the package actually appears in Reservoir.
