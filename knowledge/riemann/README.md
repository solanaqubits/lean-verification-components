# Explicit logarithmic bounds

[All sections](../README.md)

## Modules

| Module | Verified result |
|---|---|
| [RiemannBounds](RiemannBounds.en.md) | Two-sided bounds for the explicitly defined kappaCrit with coefficient −1/8, for n ≥ 1000000. |
| [RiemannMainTerm](RiemannMainTerm.en.md) | The specified main logarithmic term lies between zero and one on the stated domain. |
| [RiemannNumericBound](RiemannNumericBound.en.md) | A stronger bound placing the main term in (1/2,1). |
| [RiemannExplicitBound](RiemannExplicitBound.en.md) | The bounds kappaCrit > 63/128 > 0.49 and kappaCrit < 1, collected in a formal suite. |

## Scope

These are bounds for explicitly defined scalar functions. No connection to zeta zeros or proof of the Riemann hypothesis is established.
